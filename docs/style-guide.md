# スタイルガイド

このリポジトリのスライドが従うデザイン規範。実装は `themes/` 以下のCSSにあり、本書はその「使い方のルール」を言語化したもの。スライドを新規作成・修正するとき（人間・AIとも）は、まず本書を読んでから着手する。

- 実装の対応: カラー・部品は `themes/utility.css`、見出し・本文色は `themes/theme.css`、全体調整は `themes/global.css`
- テーマは Marp `default` テーマ継承のカスタムテーマ `hihats`（`themes/index.css`）

## デザイン原則

1. **色は「意味」で使う。装飾で増やさない** — アクセントカラーは1スライドにつき **1〜2色まで**。3色以上使いたくなったら、スライドを分割するか構成を見直す。
2. **サイズ調整より構造で解決する** — 文字が収まらないとき、まず項目を減らす・カラムに分ける。`.text-xs` 以下への縮小は最後の手段（脚注・出典表記のみ可）。
3. **1スライド1メッセージ** — 見出し（h2/h3）が主張、本文はその根拠。箇条書きは4項目程度まで。5項目以上になる場合は `::::c` で2カラム化する（項目数の選び方は `docs/writing-guide.md` のルール1も参照：3項目を避け2か4にする）。
4. **強調は控えめに** — `**strong**` と `*em*` はテーマが自動配色する（下記）。1スライド内で強調が3箇所を超えると効果が消える。

## カラーパレット

### 基調（テーマが自動適用・変更しない）

紺系グラデーションの見出し階層 + 暗紺の本文。この配色がデッキ全体のトーンを決めている。

| 要素 | 色 | 役割 |
|---|---|---|
| h2 | `#191970` (midnight blue) | セクション見出し |
| h3 | `#6565BA` | 小見出し |
| h4 | `#4e7bb5` | 補助見出し |
| 本文 p / li | `#0b0b41` / `#191970` | 基調テキスト |
| `**strong**` | `#9d5407` (琥珀) | 重要・注意の強調 |
| `*em*` | `#2eab7f` (緑) | 用語・ポジティブな強調 |
| inline code | 背景 `#faebd8` | コード・識別子 |

### アクセント（ユーティリティクラスで明示指定）

`{.クラス名}` で任意要素に付与できる9色。**用途を決めて使い、1スライド1〜2色まで**。

| クラス | 色 | 推奨用途 |
|---|---|---|
| `.red` | `#f55` | 警告・問題点・Before |
| `.blue` | `#38f` | 主張・キーワード |
| `.green` | `#2eab7f` | 解決策・After・ポジティブ |
| `.yellow` | `#e2b741` | 注意喚起 |
| `.purple` | `#673ab8` | 概念・抽象語 |
| `.light-blue` | `#61DBFB` | 技術用語（暗背景上） |
| `.gray` | `#7f7f7f` | 補足・非強調 |
| `.white` / `.black` | `#fff` / `#202228` | 背景画像上の可読性確保 |

### アラート（1スライド1つまで）

補足情報のブロック表示。`.note`（情報） / `.tip`（推奨） / `.important`（重要） / `.warning`（注意） / `.caution`（危険）の5段階。

```markdown
段落末尾に付与する {.note}

:::_ {.important}
複数行にわたる場合は
グルーピングコンテナに付与する
:::
```

## タイポグラフィ

基本サイズはテーマ既定に任せる。調整が必要なときのみユーティリティを使う。

| クラス | サイズ | 用途 |
|---|---|---|
| `.text-xl5` 〜 `.text-xl2` | 3em〜1.5em | 表紙・数字の強調（統計など）のみ |
| `.text-xl` / `.text-lg` | 1.25em / 1.125em | キーメッセージの格上げ |
| （無指定） | — | 本文の既定。まずこれで書く |
| `.text-sm` | .875em | 補足説明 |
| `.text-xs` 以下 | .75em〜.5em | 脚注・出典・URLのみ |

見出しはマークダウンの階層（`##` → h2、`###` → h3）で表現し、フォントサイズ指定で見出しを偽装しない。

## スライドタイプ（class ディレクティブ）

| class | 用途 | 備考 |
|---|---|---|
| `<!-- _class: lead -->` | 表紙・扉 | h1/h2中央寄せ・白文字。背景画像と併用 |
| `<!-- _class: invert -->` | 暗色スライド | 通常スライドの反転。章の区切りに |
| `<!-- _class: caption -->` | セクション扉（暗背景） | h2とpが中央寄せ・白文字。**暗めの背景画像が必須** |
| `<!-- _class: caption-light -->` | セクション扉（明背景） | h2とpが中央寄せ・文字色はテーマ既定。背景画像なしで使う。captionとデッキ内で混在させない |
| `<!-- _class: nolead -->` | 背景画像を主役に | 見出しを透明化して画像だけ見せる |
| `<!-- _class: minor -->` | 見出しにインパクトが要らないスライド | h2をヘッダー位置（左上）に小さく置き、本文を上から流す。インデックス・参考文献など |

出典はスライドの最下部に小さく置く。段落の末尾に ` {.source}` と書く（例: `出典: [著者, サイト名](URL) {.source}`）

表紙は `template/index.md` の形式（`_class: lead` + `_paginate: false`）に従う。

## レイアウト部品

### カラム（`::::c`）

```markdown
::::c
:::_
- 左カラムの内容
- 項目
:::

:::_
- 右カラムの内容
- 項目
:::
::::
```

等幅flexカラム。比較（Before/After、選択肢A/B）と、項目数が多いリストの分割に使う。
各カラムは `:::_` で明示的に区切る（素のリストを2つ並べても1つに結合されてカラムにならない）。外側 `::::c` のフェンスは内側より長くすること。

### 背景画像

標準は右配置 + fit。画像の情報量に応じて幅を40〜60%で調整する。

```markdown
![bg right:55% fit](images/xxx.png)
```

- 全面背景に文字を重ねるときは `![bg 75% opacity:.15]` のように透過し、必要なら `.white` で文字色を確保
- 画像はスライドと同階層の `images/` に置く

### コードブロック

ファイル名表示は ` ```js {name=filename.js} ` 記法。シンタックスハイライトは Prism（VS Code Dark+ テーマ）。

### その他

- `.fit` — ブロックを内容幅で中央寄せ
- `.m-0` `.mt-1` `.mb-1` `.ml-1` `.mr-1` — 余白の微調整（多用しない。多用が必要なら構造を疑う）
- `==テキスト=={.クラス}` — ハイライト（markdown-it-mark + attrs）

## 新規スライドの作り方

1. `pnpm new <slidename>` でテンプレートから作成（`src/<slidename>/index.md`）
2. frontmatter は `theme: hihats` / `paginate: true` / OGP用 `image:` をテンプレート通りに
3. `pnpm dev` でプレビューしながら編集
4. 画像は `src/<slidename>/images/` に配置
